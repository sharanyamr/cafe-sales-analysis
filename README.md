# Cafe Sales Analysis

## Dashboard Preview

![Cafe Sales Dashboard](dashboard.png.png)

## Project Overview

This project analyzes cafe sales data using Python and Excel. The dataset was cleaned, transformed, and visualized to identify sales trends, revenue performance, customer preferences, and business insights.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Data Cleaning

- Replaced invalid values (ERROR, UNKNOWN)
- Handled missing values
- Converted date columns to datetime format
- Created Month, Year, and Day of Week features

## Dashboard KPIs

- Total Revenue: ₹88,779.5
- Total Transactions: 10,000
- Total Quantity Sold: 30,271
- Top Selling Item: Juice

## Visualizations

- Top Selling Items
- Revenue by Item
- Payment Method Distribution
- Revenue by Location
- Sales by Day of Week
- Monthly Sales Trend

## Key Insights

- Juice was the best-selling item with 2,140 sales.
- Juice generated the highest revenue of ₹18,972.
- Total revenue reached ₹88,779.5.
- Total quantity sold was 30,271 units.
